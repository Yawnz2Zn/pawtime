# PawTime 🐾

A phone-installable web app (PWA) for pet owners: shoot photos inside the app, and they are saved
in one place and (in later versions) folded into a growth timeline.

**Status: work in progress.** The full README is added near the end of the project.

- Live app: https://Yawnz2Zn.github.io/pawtime/

## Run it locally

No dependencies and no build step. Serve this folder and open it in a browser:

```bash
python3 -m http.server 8000      # on Windows: python -m http.server 8000
```

Then open http://localhost:8000 (the camera works on localhost).
To use the camera on a phone you need an https address, which GitHub Pages provides.
